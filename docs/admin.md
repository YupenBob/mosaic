# Mosaic Admin 用户指南

云管理后台地址：`https://mosaic-admin.xsanye.cn`。零构建 Vanilla JS SPA（ES Module），无需安装。

## 登录与界面

- 输入管理员密码登录，token 存于 `localStorage`
- 顶栏：全局搜索、主题切换（auto/light/dark）、语言切换（中/英）、构建状态点、一键构建、访问站点
- 命令面板：`Ctrl/Cmd+K`；快捷键：`n` 新建文章、`Ctrl+Enter` 保存
- 未构建变更时出现黄色横幅，点击跳转构建页

## 仪表盘

- 状态卡：文章数 / 分类数 / 标签数 / 总浏览量 / R2 用量
- **分类 & 标签**：按**文章数**统计的真实分类/标签（前 8 个）
- 流量：近 30 天浏览量曲线；排行榜：热门文章
- 最近动态：文章与构建活动时间线

## 文章

- 列表：搜索、分类筛选、分页（超 100 篇分块渲染）、删除（需输入确认）
- 编辑器：标题、slug（留空自动生成）、日期、分类（`a/b` 多级）、标签、描述、布局、视频模式、封面、正文
- 草稿：编辑自动保存到 `localStorage`，离开页面有拦截提示
- 正文支持 Markdown 实时预览（自托管 marked + purify 消毒）

## 媒体上传

- 拖拽或点击选择，支持图片/视频/音乐，按扩展名自动分目录
- 上传走**预签名直传**（浏览器直连 R2，单文件最大 5GB），带进度与重试；失败自动回退 Worker 直传
- 上传完成需触发构建才会在前台生效（黄色横幅即提醒）

## 构建中心

- 概览卡：近 10 次成功率、平均时长、当前分支
- 触发"构建并部署"，进行中显示步骤级进度与预计剩余时间（ETA），构建中按钮禁用
- 历史列表：每次构建的耗时、commit、分支，失败步骤高亮并提供 GitHub 日志跳转
- 构建结束有 Toast 与标题通知；轮询按阶段调速（queued 10s / running 5s）

## 站点设置

7 个分区（基本、作者、主题布局、媒体画质、功能开关、评论、插件），全部可视化编辑：

- 站点标题/副标题/描述/URL/语言/图标（favicon 可上传，≤100KB）
- 图片画质（480p/720p/1080p）、视频 CRF / preset / **最高画质**（决定转码顶格档位）
- 组件与插件开关、Giscus 评论参数

保存为深合并，不会覆盖未展示的字段。

## 分类与标签

- 查看分类树与标签列表（含文章数）
- 重命名：逐篇改写 frontmatter 并提交
- 删除：从所有文章移除该分类/标签（文章本身保留），需二次确认

## 清理与回收站

- R2 清理：孤儿文件扫描/删除、processed 缓存清空
- 回收站：列出已删除文章（云端回收站为 stub，实时功能以本地/后端为准）

## 排障

- 登录失败：确认 `ADMIN_PASSWORD` / `JWT_SECRET` 已配置（缺失返回 503）
- 接口 401：token 过期，刷新页面重新登录
- 仪表盘异常：查看浏览器控制台；分类&标签应显示文章数而非流量
