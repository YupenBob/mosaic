# 云后台指南

后台保持原生 ES Module SPA、现有界面风格、三态主题与中英语言。用管理员密码登录，快捷键、命令面板、文章草稿、Markdown 预览和分类标签管理保留。

## 文章与上传

保存文章更新 GitHub Markdown。上传支持 Worker 直传、预签名 R2 PUT、可恢复分片上传；完成后自动登记独立媒体任务。每个上传响应包含 taskId/status，批量上传由 alarm 合并调度。编辑中离开页面仍有未保存提示；路由退出统一撤销请求、事件、草稿/预览计时器和页面轮询。

首次上传显示处理中，同名替换显示上一份已发布内容。媒体任务的启动不依赖“构建站点”按钮。删除取消相关租约；被旧部署引用的产物受到保护。

## 构建中心

媒体列表显示文件、状态、重试错误和当前阶段，可对失败/取消任务重试，也可取消单文件。离开页面即停止媒体轮询。站点部署保留 GitHub 进度、历史、运行详情、取消及手动构建。

后台只读取部署状态，不再调用完成接口清除脏标记。新的编辑或媒体更新若未被当前部署覆盖，黄色未部署提示会继续保留。网站能先显示视频低档，之后高档自动补齐。

## 配置与清理

配置页可设置图片质量、视频编码、独立媒体超时、重试、合并时间、保留天数、上传并发与部署目标；后台提交执行共享校验。完整配置字段见 [configuration.md](configuration.md)。

孤儿清理排除当前和旧部署引用。处理缓存刷新会重新排队并保留旧产物，不再立即清空整个 processed 桶前缀。任务错误排查见 [operations.md](operations.md)。
