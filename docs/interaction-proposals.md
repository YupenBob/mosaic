# Mosaic 交互级提议（v2）

> 来源：用户第 4 项「交互级别提议」。以下按“价值 × 成本”排序，标注本版是否已落地（v2）
> 与后续建议。落地项均可在 `mosaic.config.json` 的 `experience` 中关闭，关闭后回到旧行为。

## 一、本版已落地（v2）

### 1. 列表页不跳转看详情（小红书式弹层）— `experience.modal.enabled`
- **问题**：浏览照片/视频流时点开每篇都整页跳转，回退丢失滚动位置，浏览节奏被打断。
- **方案**：卡片点击打开详情层（封面/图集/正文/视频/音乐/标签/统计/点赞），History API 更新
  `?note=slug`，Esc/遮罩/返回键关闭，焦点陷阱 + 滚动锁定，移动端底部抽屉，深链刷新直达。
- **收益**：浏览路径缩短一半，移动端“刷”的手感接近小红书。
- **后续**：弹层内左右滑动切换上/下一篇；评论内联；收藏夹。

### 2. 竖屏刷视频模式（抖音手感）— `experience.verticalFeed.enabled`
- **问题**：视频列表需要逐页点开，无法像短视频一样连续消费。
- **方案**：全屏竖屏 feed，滚轮/触摸/键盘上下切换，一次只播一个，预载 ±1，双击点赞、
  单击暂停、右侧操作栏、进度条、上滑解锁/下滑关闭；默认静音自动播放，点按开启声音。
- **收益**：移动端沉浸式消费；桌面端也可以“刷”。
- **后续**：下滑进入作者主页/合集；评论区半屏；算法排序（点赞/播放完成率）。

### 3. Spring 动效体系 — `experience.motion.spring`
- **问题**：现有过渡是线性 cubic-bezier，弹层/卡片“生硬”，缺乏物理感。
- **方案**：统一 spring 积分器（snappy / smooth / bouncy 三档），用于卡片按压回弹、弹层
  进出、菜单展开、主题切换；统一尊重 `prefers-reduced-motion`。
- **收益**：同样的功能，主观“高级感”显著提升；参数集中，后续可全局调节。
- **后续**：手势拖拽与 spring 联动（弹层下拉关闭、feed 滑动阻尼）。

### 4. Morphicons 状态图标
- **问题**：RemixIcon 是静态字体图标，主题切换/播放暂停/点赞等状态切换是“硬切”。
- **方案**：Morphicons（spring 形变）用于有状态的交互图标：sun↔moon、play↔pause、
  heart↔heart-filled、menu↔close、chevron 等；静态装饰图标继续用 RemixIcon（体积最优）。
- **收益**：状态变化“看得见”，与 spring 动效语言一致；无新字体请求。
- **后续**：更多状态对（音量/静音、画质、收藏）。

### 5. 卡片信息层级重排 + 全图
- 大图优先、标题/描述/统计分级，hover 轻微上浮 + 图片缓推；文字卡片降级为纯排版卡。
- **收益**：列表本身成为作品集；移动端首屏信息密度更合理。

### 5.1 瀑布流 + 几 KB 预览图 + 超椭圆圆角（v2.1）
- **瀑布流**：每列首尾相接，每张卡片按自身封面比例决定高度（不再被统一比例裁切）；
  `experience.card.layout=masonry|grid` 可切换。
- **预览图优先**：首屏先请求 1–6KB 的模糊预览图占位，高清图解码后原位替换；首屏卡片并行走
  高清以守住 LCP，其余接近视口再升级；无 JS/旧媒体自动回退。
- **超椭圆圆角**：卡片/弹层/按钮放大圆角，支持的浏览器使用原生连续曲率（squircle），其余
  回退普通圆角，不牺牲阴影与响应式。
- **收益**：更接近小红书/作品集的浏览触感；首屏图片字节显著下降，滚动不再“跳图”。


### 6. 主题开放（三种模式 + 主题色）
- auto/light/dark + 6 套 accent 色板；首帧无闪烁；后台可设默认值与是否允许访客切换。
- **收益**：站点品牌可定制；访客获得符合环境的默认值，又不被强制。

### 7. 视频“解码/播放”意图分离
- 点击前**零媒体请求**（只留 poster），点击后先 240p 首片再 ABR 升档；重复点击/切档/重进
  不产生第二路下载；HLS 致命错误自动降级 MP4。
- **收益**：首帧更快、流量更省、弱网更稳。

### 8. 后台“可解释”的媒体任务
- 任务展示：档位进度、补帧状态、是否保留源文件、失败原因/重试按钮；批量补帧有确认与进度。
- **收益**：把“等待玄学”变成可见状态，降低误操作。

## 三、交互设计原则（v2 起统一遵守）

1. **意图优先**：媒体下载/解码只在用户表达意图后触发；预加载必须有明确策略与上限。
2. **可中断**：任何动画/请求/播放器实例都能被新的用户操作立即取消，不排队不叠加。
3. **物理感但克制**：spring 用于状态变化（按压/开关/进出），滚动与视频播放不叠加弹簧。
4. **可达性不妥协**：焦点可见、Esc 可退、屏幕阅读器语义、reduced-motion 下退化为淡入淡出。
5. **渐进增强**：弹层/竖屏模式/View Transitions 不可用时，基础链接导航必须仍然工作。
6. **可关闭**：所有体验增强都有配置开关；关闭后行为与旧版一致。
