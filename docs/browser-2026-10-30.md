# 浏览器侧优化记录（2026-10-30）

本轮针对**浏览器内的前台体验**做功能性、视觉性与兼容性收口，不涉及媒体处理、
R2 清单或站点构建契约；`dist/` 仍由 `npm run build` 生成。

## 功能性

| 项 | 改动 |
| --- | --- |
| 搜索可访问性 | 搜索框改为 WAI-ARIA combobox：`aria-expanded/controls/autocomplete/activedescendant`，下拉为 `listbox`，结果为 `option` |
| 键盘操作 | `↓/↑` 移动结果、`Enter` 打开当前（无选中时打开第一条）、`Esc` 关闭（再按清空查询）、`Tab` 关闭并离开 |
| 快捷聚焦 | 页面上按 `/` 直接聚焦搜索；输入框、弹层或全屏 feed 打开时不抢焦点 |
| 输入法 | 显式跟踪 `compositionstart/end`，拼音等组合输入期间不筛选、不弹结果，避免半截拼音闪空态 |
| 防竞态 | 清空或继续输入会作废上一次防抖回调，旧查询不会在 250ms 后“复活”下拉 |
| 触屏交互 | 卡片 hover 抬升/封面缩放仅在 `(hover: hover) and (pointer: fine)` 生效，避免点按后卡片“粘”在浮起状态 |
| 弹层滚动 | 详情弹层、画廊补 `overscroll-behavior: contain`，阻止滚轮/触摸惯性穿透到背景页面 |
| 移动浏览器栏 | 文章页与 404 补齐 `theme-color`，并在首帧主题脚本里同步深/浅色，状态栏与页面不再割裂 |

## 视觉性

| 项 | 改动 |
| --- | --- |
| 移动端筛选区 | 分类/标签从 4–6 行换行改为各一行横向滑动，标签（分类:/标签:）用 sticky 固定在左侧；首屏卡片位置约提前 100px |
| 搜索下拉 | 选中项增加强调色左侧标记与 hover/选中背景；空结果使用本地化文案与专属样式；高亮词条样式统一 |
| 搜索提示 | 桌面端输入框右侧显示 `/` 键提示，聚焦或有输入时淡出；触屏设备隐藏 |
| 深色对比度 | 深色 `--color-text-secondary/tertiary` 提升到 `#aeaeb2/#a8a8ad`，在 `surface-hover` 上仍 ≥ 4.5:1（axe 验证） |
| 兼容回退 | `color-mix()` 之前补纯色回退（页头、文字卡、卡内分类标签）；画廊/视频/播放列表高度补 `dvh`，兼容移动端地址栏收放 |

## 验证

- `npm run build`、`npm run check`、`npm run lint`、`npm run format:check` 通过
- `tests/a11y-front.mjs`（本地构建，5 个页面 × 明暗两主题）0 违规
- 搜索下拉打开状态下 axe（WCAG 2.2 AA）0 违规
- Chromium 实测 1440×900 / 390×844：`/` 聚焦、`↓/↑/Enter/Esc`、点击外部关闭、
  IME 组合输入、分类 + 搜索组合、清空防抖、深色 `theme-color` 均符合预期
- 移动端无横向溢出；筛选区高度由约 190px 降至约 100px（含搜索）

## 环境限制

本机为 Alibaba Cloud Linux 3（无 apt，Playwright 不支持该发行版），WebKit 所需
GTK/GStreamer 等系统库无法安装，因此 `npm run test:e2e:local` 中的 WebKit 段
无法在本机执行；Chromium 段已用等价脚本逐项验证。CI 的 `verify.yml` 仍会覆盖
Chromium + WebKit。
